SP Football Life 2027용 대회 이름·대회 규정 본문 한글화 배포물입니다.

## 릴리즈

| 항목 | 내용 |
| --- | --- |
| 릴리즈 태그 | `v1.0.0` (이 저장소의 첫 릴리즈) |
| 기준 게임 | SP Football Life 2027 |
| 작업 반영일 | 2026-11-02 |
| 규정 CPK | `dt20_kor_x64.cpk` (size `18424128`, md5 `d715dbddcdbe1f117112c449073dd199`) |
| 대회명 BIN | `CompetitionRegulation.bin` (size `460992`, md5 `5aa3c2ae0c3a0a104501681e98fb73e7`) |

- **규정**: 한국어 `dt20` 안의 대회 규정 **본문**을 한글화한 파일입니다. (대회 이름 파일이 아닙니다.)
- **대회명**: 리그·컵 등 대회 표시명을 한글화한 `CompetitionRegulation.bin`입니다. Sider livecpk로 덮어씁니다.

SP FL 27 1.00 이후 버전에는 그대로 덮어쓰지 말아주세요. 패치로 DB·표시 문자열이 바뀌면 재작업이 필요합니다.

## 적용 방법

### 1) 규정 (`dt20_kor_x64.cpk`)

1. 게임을 종료해 주세요.
2. 기존 파일을 백업해 주세요.  
   `SP Football Life 2027\Data\dt20_kor_x64.cpk`
3. 이 배포의 `dt20_kor_x64.cpk`로 덮어써 주세요.
4. 게임을 실행한 뒤 대회 규정 설명이 한글로 나오는지 확인해 주세요.

### 2) 대회명 (`CompetitionRegulation.bin`)

1. 게임을 종료해 주세요.
2. 아래 경로에 파일을 넣어 주세요. 폴더가 없으면 만들어 주세요.  
   `SP Football Life 2027\SiderAddons\livecpk\root\common\etc\pesdb\CompetitionRegulation.bin`
3. Sider를 켠 뒤 게임을 실행해 대회명이 한글로 나오는지 확인해 주세요.

두 파일은 역할이 다릅니다. 규정 CPK만 넣으면 대회 이름은 그대로일 수 있고, 대회명 BIN만 넣으면 규정 본문은 그대로일 수 있습니다.

## 참고

- 규정 패치는 자리표시자(`%d` 등)와 제어 문자를 유지한 채 본문만 번역했습니다.
- 대회명 표기 표준: 공식 한글명에 나라·국적 표기가 없으면 뒤에 `(나라)`를 붙이고, 이름에 이미 포함되면 그대로 둡니다.  
  예: `프리미어리그 (잉글랜드)`, `브라질레이랑 세리 A`
- 선수 이름 한글화는 별도 저장소입니다: https://github.com/choepd/FL27-player-names-ko
